# 天枢 · 校内采集器（Chrome 扩展）

把「学在城院 / 爱城院」网页上本来就在加载的通知、待办、课程数据，顺手复制一份存进本机的天枢。
**不经过任何服务器**，所有数据只写进 `127.0.0.1:7311`。

## 它能做什么

- 在你正常浏览校园网站时，拦截页面自己发出的 `/api/`、`/dapi/` JSON 响应，转交本地天枢入库
- 打开某门课的页面时，自动把整门课（章节 / 课件 / 作业）同步一次，6 小时内不重复
- 打开课程列表页时，自动同步全部课程，12 小时一次
- 抓不到就进队列重试，弹窗里能看到待上传条数、最近一次结果、页面最近请求和事件日志

## 安装（开发者模式加载）

1. 把本目录整个下载到本地
2. Chrome 打开 `chrome://extensions`，右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选中本目录
4. 保证本地天枢在跑（`npm start`，默认 `http://127.0.0.1:7311`），点扩展图标应显示「已连接」

## 权限说明

| 权限 | 为什么需要 |
| --- | --- |
| `host_permissions: *.hzcu.edu.cn` | 只在这两个校园域名上注入，用于复用你已经登录的会话 |
| `host_permissions: 127.0.0.1:7311` | 把抓到的数据交给本机天枢 |
| `scripting` / `activeTab` | 手动触发「强制注入」和「抓当前页快照」排障按钮 |
| `storage` | 本地队列与去重时间戳 |

没有 `cookies`、没有 `webRequest` 全量监听、没有远程地址。

## 文件

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | MV3 清单，v0.9.1 |
| `inject.js` | 页面世界（MAIN world）钩住 fetch / XHR，副本交给扩展，不改页面行为 |
| `content.js` | 隔离世界，只做消息搬运 |
| `background.js` | 推送、失败重试队列、去重、事件日志 |
| `popup.html` / `popup.js` | 状态面板与手动触发按钮 |

## 已知限制

- 只适配「学在城院」「爱城院」，换学校要改 `manifest.json` 里的域名与 `background.js` 里的接口路径
- 校园站点改版后接口路径可能变，此时用「抓当前页快照」导出真实请求再调
